# Third-Party Notices & Licenses

This project incorporates, adapts, or interfaces with several open-source software libraries and toolchains. We gratefully acknowledge the creators and contributors of these technologies:

---

### 1. Anatomy Kit (`vendor/anatomy-kit/iso-kit.mjs`)
- **Description**: Isometric 3D vector geometry projection and polygon rasterization engine for SVG figures.
- **Role**: Provides core algorithms for face normal calculation, lighting buckets, and isometric projection matrices.
- **License**: MIT License / Open Source.

---

### 2. HyperFrames (`@hyperframes/cli`)
- **Description**: Declarative HTML/CSS/Web-Standards video synthesis engine.
- **Website**: https://hyperframes.heygen.com
- **Role**: Provides headless browser timeline orchestration, visual contrast and quality gate checks, and frame-by-frame canvas capture to MP4.

---

### 3. GreenSock Animation Platform (GSAP)
- **Description**: Industry standard JavaScript animation library.
- **Website**: https://greensock.com
- **Role**: Provides declarative, pause-seekable timelines for inline SVG exploded layers, parts animation, and camera motions.
- **License**: Standard GreenSock License.

---

### 4. Edge-TTS (`edge-tts`)
- **Description**: Python interface to Microsoft Edge's text-to-speech service.
- **Website**: https://github.com/rany2/edge-tts
- **Role**: Zero-cost, low-latency audio generation with millisecond-precision `WordBoundary` timestamp extraction.
- **License**: GNU Lesser General Public License v3.0 (LGPL-3.0).

---

### 5. FFmpeg & FFprobe
- **Description**: Complete, cross-platform solution to record, convert, and stream audio and video.
- **Website**: https://ffmpeg.org
- **Role**: Audio duration probing, sample rate normalization (44.1kHz), and container-level cover poster (`attached_pic`) injection.
- **License**: LGPL v2.1+ / GPL v2+.
